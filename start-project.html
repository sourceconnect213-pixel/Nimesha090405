Project idea එක
05

Project idea එක

ඔයාට කරගන්න ඕන දේ සරලව ලියන්න. Technical වචන ඕන නෑ.

AI එකකට උදව්: මොන website / dashboard එකටද, chatbot එකට FAQ කීයක්ද, documents තියෙනවද (කීයක්, pages කීයක්), මොන database එකද (Firebase / Supabase), automation එකේ input / output මොනවද, language එක, දැනට OpenAI / Make / n8n accounts තියෙනවද. Package එකේ නැති දෙයක් ඕන නම් මෙතන ලියන්න, වෙනම quote එකක්. Maintenance එකකට උදව්: site / app / server එක මොකක්ද (static, WordPress, WooCommerce, Firebase / Supabase, VPS), pages / plugins / products කීයක්ද, hosting / backups කොහෙද, දැනට ප්‍රශ්න තියෙනවද (hacked, outdated), මොන වෙලාවට support ඕනද. Unhealthy system එකකට initial audit එකක් වෙනම quote වෙනවා. Backend / admin එකකට උදව්: දැනට තියෙන app / site එක මොකක්ද (Flutter / web, code access තියෙනවද), Firebase project එකක් දැනටමත් තියෙනවද, save කරන data modules මොනවද, admin එකේ කවුද වැඩ කරන්නේ (roles), uploads / reports / APIs ඕනද, users කීයක් විතරද. Package එකේ නැති දෙයක් ඕන නම් මෙතන ලියන්න, වෙනම quote එකක්. Website එකකට උදව්: pages / views මොනවද, products හෝ services කීයක්ද, photos තියෙනවද, enquiry form / payments / login ඕනද, දැනට domain / hosting / WordPress account තියෙනවද. Package එකේ නැති දෙයක් ඕන නම් මෙතන ලියන්න, වෙනම quote එකක් දෙනවා. App එකකට උදව්: screens මොනවද (නම්), කවුද use කරන්නේ (customer / staff / admin), save කරන data, photos / files uploads, payments, notifications, දැනට තියෙන Firebase / Play Store accounts. Package එකේ නැති දෙයක් ඕන නම් මෙතන ලියන්න, වෙනම quote එකක් දෙනවා. පොඩ්ඩක් විස්තර කරන්න (අකුරු 15 කට වඩා).
